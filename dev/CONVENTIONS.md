# Conventions

Entry format used in every section file:

```markdown
- **[Title](url)** - *Type, Mon YYYY.* One-line "why it matters". *Rough edges/caveats (optional).*
```

- **Dates:** `Mon YYYY` (or `YYYY` if the month is unknown), newest first within each group. Look dates up rather than guess; do not hide them.
- **One line per item:** "why it matters" is a concrete outcome, not adjectives. Numbers only when defensible ("influenced revenue," never "revenue generated").
- **Role clarity:** mark each item as *author*, *co-author*, *editorial support*, *developed (presented by colleague)*, or *contributor*.
- **Tone:** first-person, plain, honest about rough edges and what is dated. No hype.
- **Public only:** every item must be reachable by a stranger without login. AWS-owned repos: link them, but describe my role accurately.
- **Currency:** dates on each item show how current it is; the link check runs weekly.
- **Length:** best-of at the top, the rest in `<details>`.
- **No private material:** no Cirro code, internal decks, or non-public customer names.
- **License:** CC BY 4.0 for text.
